# Data and attribution

Code and first-party editorial annotations are offered under the repository Apache-2.0 license. Source links identify third-party publications; their articles, brands, templates and other original materials retain their own rights. This package includes no source article bodies or quotations. Linking is not endorsement or professional identity verification.

The JSON fixture deliberately includes public, validated method payloads and reported outcomes/opinions for reproducible experiments. It is not a production database dump. Original public IDs remain reference metadata; local imports allocate their own IDs idempotently and write a mapping. Artifact hashes in reported results identify the contributor's original artifact; they do not upload that artifact or independently prove a reported result. Private vaults, tokens, internal service state and retired Samsung data are excluded.

The included benchmark is a dated development observation. Reusing its questions is a regression, never a new independent holdout. The earlier technical no-material set failed 0/4 abstentions on the expanded corpus. Preserve these failures when reporting results.
